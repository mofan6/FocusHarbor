# Focus Harbor 1.0.0 · 首次公开发布

下载附件 **FocusHarbor-Portable.exe** 即可运行，文件约 322 KiB。

## 功能

- 浏览器白名单与多浏览器自动发现，本地 HTML、PDF 保持可用。
- 桌面应用、Microsoft Store 应用及普通文件守卫，支持独立允许时段。
- 每日 3 次、每次 30 分钟临时解除；支持立即恢复专注和主动放弃当天剩余额度。
- 可增删、重命名的学习科目与手打说明奖励。
- 晨间唤醒、音乐闹铃、逐字打字任务与正确率反馈。
- 本地累计专注时长、自动保存和可搜索的内嵌 Markdown 教程。

首次启动全部防护默认关闭，应用守卫无预置规则。截图、构建方法和使用说明见仓库 README。

## 使用前注意

晨间闹钟超时会触发已配置的文件夹可恢复隔离（120 小时）、当日解除锁定及 Codex 本机组件限制。请先阅读教程，使用专用文件夹并另行备份。硬件唤醒和锁屏播放受系统条件影响，不能保证关机自启；不要将其作为唯一的起床保障。
