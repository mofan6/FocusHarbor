# 开发检查工具

本目录是独立 C# 检查入口的源码，不会被常规 `build.ps1` 编译进应用。需要开发者另行指定入口、引用与嵌入资源后编译，不提供“一键全部运行”。

- `FileGuardHarness.cs`：只针对自动创建的临时样本，实测新读取阻止、原权限恢复、损坏主记录恢复、改名后按文件身份恢复、快捷方式解析，以及 EXE 启动拒绝和精确路径进程拦截；不运行真实闹钟或真实守卫配置。

- `PauseStoreHarness.cs`：普通额度放弃、提前恢复、商店应用身份及旧规则删除；常规入口将状态重定向到临时目录。
- `CloseSaveHarness.cs`：关闭时的草稿合并、后台保存与失败恢复；常规入口使用隔离状态。
- `LogicAuditHarness.cs`：互斥、状态归一化、应用分类、奖励和路径校验等回归。
- 其他 `*Harness.cs`：用于界面、资源或特定功能的开发检查。运行前必须阅读相应入口。

**不要在主力使用环境中直接运行整个测试目录，也不要触发真实闹钟惩罚。** 某些工具或显式的 `live-*` 参数会访问真实配置、窗口、进程、策略或计划任务。应在独立 Windows 测试用户或虚拟机内检查，并备份原有配置。发布程序不需要运行这些工具。
